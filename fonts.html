🔤 Font Converter

Converts TTF/OTF fonts into .cpfont files the reader loads from the SD card — including kerning and ligature data extracted from the font.

1. Name your font

Letters and numbers. This is the name you pick in the reader's font settings.

Pairing with the reader's Japanese and Chinese fonts

Name a family NotoSansJP, NotoSansSC, NotoSansTC or NotoSansHK (or the NotoSerif… equivalent) and it pairs with the reader's built-in Noto entry as its Japanese, simplified- or traditional-Chinese half, chosen by each book's language.

2. Add the font files

Select every style of the family together. Regular, Bold, Italic and Bold Italic are recognised from the file names, e.g. Literata-BoldItalic.ttf.

or pick each style
Fallback font (optional)

Fills in characters the main font lacks, e.g. a Japanese font behind a Latin one. Only its regular style is used.

3. Languages and symbols

Pick the scripts your books use. Each one makes the files larger, so leave out what you don't read.

Japanese and Chinese
Advanced coverage

“Everything in the font” costs device RAM. It records one interval per run of glyphs present, and the reader keeps that table in RAM while the font is loaded. A Noto Sans JP build measured 26,592 bytes, against 390 for the same coverage via Japanese, on a device whose largest free block is often under 32 KB.

Presets: ascii, latin1, latin-ext, greek, cyrillic, hebrew, georgian, armenian, ethiopic, vietnamese, punctuation, cjk, cjk-ext, cjk-zh, chinese, hangul, cherokee, tifinagh, symbols, reading, builtin, all.

4. Sizes

One file per size. The reader offers each size you build.

How to install

  1. Unzip the download at the root of the SD card. It holds .fonts/<Family>/<Family>_<size>.cpfont; the .fonts folder can be hidden in your file manager, which is normal.
  2. Or upload the files over Wi-Fi with the reader's Fonts page.
  3. Pick the font in the reader's font settings.

Glyphs are drawn by your browser's font engine, so edges can differ very slightly from the desktop tool; metrics, kerning and ligatures come from the font file and match exactly.

Output matches lib/EpdFont/scripts/fontconvert_sdcard.py (.cpfont v4) from the matcha-reader firmware.

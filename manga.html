📖 Manga Converter

AI panel detection for manga, in your browser. Finds the panels, optionally reads and translates their text with Gemini, and exports for the Matcha Reader, as EPUB, or as XTC.

1. Choose your manga

Page order follows the same natural filename sort the device uses (cover and copyright pages pinned first). EPUBs use their spine order and native table of contents automatically; PDFs use document order (pages rasterized at 2× like the desktop tool).

5. Book details (optional — auto-detected from EPUB/ComicInfo when present)

Set the language so the reader can split your reading stats by language. Only EPUBs and CBZs with a ComicInfo.xml declare one, so for anything else it stays empty unless you fill it in here. Read at conversion time — a book converted without it counts as "unknown" until you convert it again.

OCR sends each panel image to the Gemini API and can take a while for a full volume — keep this tab open. The screen is kept awake during conversion. On the free API tier, rate limits may make long volumes slow; the converter retries automatically.

Install on the device

The download is a zip with one folder (named after the title). Put that folder anywhere on the SD card — /manga/YourTitle/ is a nice convention — either with a card reader or via the reader's Wi-Fi web file transfer. The device finds any folder containing panels.idx automatically, at any depth.

Output matches tools/manga_convert/convert_manga.py from the matcha-reader firmware — including its YOLO panel detector (in-browser via ONNX Runtime) and PDF input (in-browser via PDF.js).

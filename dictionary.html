📚 Dictionary Converter

Converts a dictionary into the reader's binary lookup format (.idx + .dat), including the .spx sidecar that makes on-device lookups fast. Japanese, Chinese and Cantonese dictionaries each go to the folder the reader looks in for that language.

2. Choose the dictionary file(s)

Sources: Jitendex (Japanese vocabulary), JMnedict in Yomitan format (Japanese names), CC-CEDICT (Chinese, both scripts), the Taiwan Ministry of Education's dictionary as g0v dict-revised.json (unpack the .xz first), and CC-Canto (Cantonese). Chinese files picked together merge into one dictionary: a word in both shows both entries.

4. Which dictionary slot is this?

Large dictionaries (Jitendex is ~60 MB, the MoE dictionary ~140 MB unpacked) take a minute and some memory to convert — everything stays on your device.

Install on the device

The download is a zip containing the folder the reader looks in for the chosen language, /dict/. Unzip it at the SD card root (or upload the files there via the reader's Wi-Fi web file transfer). The firmware's own layout documentation lists /dictionaries/jp/, /dictionaries/zh/ and /dictionaries/yue/; Japanese files in /dict/ keep working. After installing all three slots a language's folder looks like:

vocab.idx    vocab.dat    vocab.spx    vocab.title      (vocabulary — required)
names.idx    names.dat    names.spx    names.title      (names — optional)
grammar.idx  grammar.dat  grammar.spx  grammar.title    (grammar — optional)

A Chinese vocabulary converted with Proper nouns to their own names dictionary ticked writes names.* beside vocab.* in one go. One dictionaries/zh/ serves simplified and traditional books alike; a Cantonese book (tagged yue) reads dictionaries/yue/ instead.

Output matches tools/dict_convert/convert_jmdict.py and scripts/gen_dict_spx.py from the matcha-reader firmware byte-for-byte.
